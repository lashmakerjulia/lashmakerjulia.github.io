САЙТ "ЮЛІЯ LASHMAKER" — ІНСТРУКЦІЯ
====================================

СТРУКТУРА ПАПОК
----------------
index.html            — головна (і єдина) сторінка сайту
css/style.css          — усі стилі та кольори сайту
js/script.js           — вся інтерактивність (меню, анімації, галерея)
images/brand/logo-circle.png — логотип (кругла емблема, вирізана з прозорим фоном)
images/brand/favicon.png     — маленька іконка сайту (вкладка браузера)
images/brand/logo.jpg        — оригінальний файл лого (на всякий випадок)
images/hero/                 — фонові/атмосферні фото (стиль сайту)
images/about/julia.jpg       — фото Юлії у блоці "Про мене"
images/catalog/              — фото робіт для каталогу (work-01.jpg … work-14.jpg)

Просто завантажте всі ці папки і index.html на хостинг,
зберігаючи структуру як є — сайт запрацює одразу.


ЯК ЗМІНИТИ ЦІНИ
----------------
Відкрийте index.html, знайдіть блок <section class="services" id="services">.
Кожна послуга — це один блок <div class="price-card">.
Число всередині <div class="price">600 <small>грн</small></div> — і є ціна.
Просто заміните цифру на нову.

Додаткові послуги (промінчики, зняття) знаходяться трохи нижче,
у блоці <div class="price-extra">.


ЯК ДОДАТИ / ЗАМІНИТИ ФОТО РОБІТ У КАТАЛОЗІ
--------------------------------------------
1. Додайте нове фото у папку images/catalog/, назвавши його,
   наприклад, work-15.jpg (бажано квадратне/вертикальне фото,
   приблизно 1000×1250 px, щоб каталог виглядав акуратно).
2. В index.html знайдіть <section class="catalog" id="catalog">
   і скопіюйте один блок .catalog-tile, замінивши шлях до фото
   на новий (наприклад images/catalog/work-15.jpg).

Кожна плитка каталогу автоматично перемикає між двома фото —
це і є ефект "фото змінюються самі". Просто вкажіть у плитці
два різних файли (два теги <img>), якщо хочете анімацію.

ЯК ЗМІНИТИ ФОТО ЮЛІЇ / ДИПЛОМИ
-------------------------------
Фото Юлії вже стоїть у блоці "Про мене" — файл
images/about/julia.jpg. Щоб замінити на інше фото, просто
покладіть новий файл під тією ж назвою (julia.jpg) у цю ж папку.

Якщо є скани дипломів/сертифікатів — можна додати їх як окремі
картинки в новий блок поруч (за потреби можу підготувати
окремий розділ "Сертифікати" з рамками під ці фото).


ЗАВАНТАЖЕННЯ НА GOHOST / ІНШИЙ ХОСТИНГ
-----------------------------------------
1. Заходьте у файловий менеджер хостингу (зазвичай папка public_html).
2. Завантажуєте туди ВСІ файли й папки з цього проєкту одним разом,
   зберігаючи структуру (index.html — у корені, css/js/images —
   поруч, як окремі папки).
3. Перевіряєте сайт за адресою вашого домену.

Готово — сайт адаптивний і однаково добре виглядає
на телефоні, планшеті й комп'ютері.
